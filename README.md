# 🦉 ฮูก Clear · สำนักงานพัฒนาชุมชนจังหวัดสงขลา

หน้าเว็บแบบไฟล์นิ่ง (GitHub Pages) ของระบบ ฮูก Clear — **ไฟล์ในนี้สร้างอัตโนมัติ ห้ามแก้ตรงนี้**
(แก้ที่เทมเพลตในโปรเจกต์ Apps Script แล้วรัน `node tools/build-web.js`)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บประชาชน — โหลดข้อมูลสาธารณะ (ตัวเลขรวม/เนื้อหาที่เจ้าหน้าที่เผยแพร่แล้ว) จาก Apps Script |
| `staff.html` | แดชบอร์ดเจ้าหน้าที่ — เปิดได้จากลิงก์ส่วนตัวใน LINE เท่านั้น (ลิงก์หมดอายุตามที่ตั้งไว้) |

ไม่มีข้อมูลหรือรหัสลับใด ๆ อยู่ใน repo นี้ — ข้อมูลทั้งหมดอยู่ใน Google Sheet ของสำนักงาน
